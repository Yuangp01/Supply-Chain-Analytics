the primary reporting interface.

<h3>How I Built the Tooltips</h3>

<ol>
  <li>
    <strong>Report-Page Configuration:</strong>
    Created dedicated tooltip pages in Power BI with
    compact canvas dimensions optimized for contextual
    analysis.
  </li>
  <li>
    <strong>Custom HTML/CSS Design:</strong>
    Built four-card KPI layouts with consistent spacing,
    typography, icons, and semantic color coding.
  </li>
  <li>
    <strong>Dynamic DAX Measures:</strong>
    Integrated financial and shipping KPIs designed to
    respond to the applicable report filter context.
  </li>
  <li>
    <strong>Tooltip Integration:</strong>
    Configured relevant report visuals to display
    supporting information through report-page tooltips.
  </li>
  <li>
    <strong>Layout Optimization:</strong>
    Refined card dimensions and content density to
    maintain readability within limited tooltip space.
  </li>
</ol>

<h3>Why This Matters</h3>

<ul>
  <li>
    <strong>Progressive Disclosure:</strong>
    Keeps primary dashboards clean while providing
    additional detail when users need it.
  </li>
  <li>
    <strong>Contextual Insights:</strong>
    Brings related financial and operational metrics
    together during analysis.
  </li>
  <li>
    <strong>Consistent User Experience:</strong>
    Maintains visual hierarchy and semantic colors
    across dashboard components.
  </li>
  <li>
    <strong>Efficient Navigation:</strong>
    Reduces the need to switch report pages to
    retrieve supporting KPI information.
  </li>
</ul>
